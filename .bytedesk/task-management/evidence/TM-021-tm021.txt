The main content narrows and gives the width back. A third flex child of .shell,
not an overlay - which matters because a terminal grid and a chart each measure
their own container, so a panel on top of either is useless.

NO CSS TRANSFORM. fitmatrix.js records that a transform resamples terminal glyphs
into mush. Width is animated and the re-fit fires on transitionend, not per
frame; four earlier fitting attempts oscillated because a measurement at the
current size fed the choice of the next size. agentmux:blade-resize is dispatched
once the width settles.

THREE STATES, persisted: hidden / overlay / pinned. Drag-resize snapped to 20px
and clamped 320-900, keyboard-reachable. Ctrl+` toggles, Ctrl+Shift+` swaps
pinned and overlay. Below 900px pinned overlays instead, because it cannot reflow
to a useful width.

A BUG IN MY OWN CODE, caught by the suite: blade.js assumed .style existed and

THE CONSOLE RUNTIME IS INTERIM AND SAYS SO IN THE SOURCE. ADR-0023 chose the
Agent SDK inside the Node API, which does not exist yet, so /api/blade/send
shells `claude -p`: no continuity between turns, no tool use, no streaming. It is
NOT send-keys into a pane - a fresh headless process cannot reach an existing
agent's session, so SPEC_agentmux.md's "terminals stay read-only" is untouched.
