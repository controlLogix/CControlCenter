not loaded Selecting a method is safe from here. Entering a credential is not — those commands are shown for you to run in a terminal.

Methods are declared in dashboard/auth.json; machine-specific settings live in ~/.agentmux/auth.json and secrets in ~/.agentmux/env, both 0600. agentmux sources the env file into each pane rather than putting values on a command line, so a key never reaches ps or your shell history.
